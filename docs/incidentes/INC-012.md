# INC-012 — Builds de CI fallan de forma intermitente en `next/font` (11 nov 2026)

**Impacto:** sin impacto en producción. Dos pruebas de humo de PR fallaron en el paso «Construir» (`perf/req-1563-transformations` run 43128528864 y `feat/mapa-viajes-y-tangol-ola2` run 43127463796) con `An error occurred in next/font. TypeError: Cannot read properties of null (reading '1')`. Cualquier deploy de `main` podía fallar igual.

**Contención:** relanzar la ejecución fallida (la falla es intermitente).

**Causa raíz (5 porqués):**
1. El build falla en `next/font`. → 2. `next/font/google` descarga el CSS y las fuentes de Google en cada build. → 3. A veces la respuesta de Google al runner de GitHub no trae el formato esperado (error o límite de tasa), y `next/font` no lo tolera. → 4. Desde el PR #360 (REQ-1560) las fuentes se movieron de un `@import` en el navegador a `next/font/google` en el build. → 5. El build quedó dependiendo de un servicio externo sin respaldo.

**Por qué ningún test lo detectó:** los tests unitarios no hacen el build, y el build local del PR #360 sí llegó a Google; la falla es intermitente.

**Corrección (REQ-1616):** `next/font/local` con los `.woff2` latinos de Fontsource (OFL, licencia incluida) en `src/app/fonts/`. Mismas familias, pesos y variables CSS; el build ya no sale a internet por fuentes. Test `src/perf/fonts.test.ts` (REQ-1616) verifica que no se use `next/font/google` y que cada archivo citado exista.
